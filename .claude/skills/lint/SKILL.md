# lint

Wikiの健全性をチェックして報告する。

## チェック項目
1. **矛盾**：相反する記述（concept内/ページ間）を列挙。
2. **孤立ページ**：どこからも `[[wikilink]]` されてないページ。
3. **知識ギャップ**：concept に対し根拠ソースが薄い/古い箇所。
4. **古さ**：`updated` が古く、状況変化が疑われるページ。
5. **重複**：似た concept が分裂してないか（統合候補）。

## 出力
- 各項目を箇条書きで報告。
- **自動修正はしない**。修正案を人間に提案するに留める。
- 重大な矛盾/ギャップは log.md にも記録。
