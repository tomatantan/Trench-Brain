# query

Wikiに質問して、蓄積知から横断的に答える。

## 手順
1. 質問を理解し、関連する concepts / summaries を読む。
2. **横断で**答える（単一ソースの引き写しでなく、複数ソースの交差点から）。
3. 根拠を `[[wikilink]]` で明示。確証が薄い所は「ソース不足」と正直に書く。
4. 回答が再利用価値ありなら `wiki/queries/<質問の短い名>.md` に保存（type: query）。
5. 回答中に見つけた知識ギャップは log.md にメモ（次の ingest候補）。

## 注意
- Wikiに無いことは創作しない。「未収録」と言う。
- 投資/トレード示唆は仮説として書く（断定しない）。
