Most NFT-token pairings use ERC-404s. @OxSimpleFarmer deliberately didn't, and explained why today on stream.

404s and tax tokens break when a token lists on a centralized exchange, the flywheel falls apart. So $Stonkbrokers uses a classic ERC-20 + ERC-721C, and builds the mechanics with separate smart contracts instead.

How it works: an AMM between the NFT and token charges a fee that funds rewards. Activating an NFT requires burning the native token (deflationary, already ~10% of supply burned), and every NFT transfer nullifies activation, so it has to be re-activated to keep earning.
