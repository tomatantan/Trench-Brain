Johann Kerbrat explains how Robinhood balances the permissioned and permissionless sides of its chain

"The network itself, the blockchain, is permissionless. But where we want to spend time on is how do we introduce the customers into the chain. For us it's really on the application side that we spend a lot of time on"

"If you're using the Robinhood wallet, for example, which is kind of the official wallet for the Robinhood chain, we are connected to multiple providers that are scanning the different tokens that are accessible to make sure there are no security issues on the token, or that it's not a rugpull basically. If at some point we see this provider telling us, hey this token is a problem, we will actually display a banner on the application and warn the user that this is probably something that they should not do"

"The wallet has a jurisdiction system in it, so if you're a US customer using the wallet, you cannot trade the stock tokens. But if you're in one of the jurisdictions that is allowed, you can actually use it. That's where we really spend a lot of time on"
