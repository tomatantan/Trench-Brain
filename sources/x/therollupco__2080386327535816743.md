Leo Fan explains why a free open-source model still ends up priced near Opus 4.8 by the time you run it.

"There's a huge bottleneck on the compute side. You train on the latest GPUs, but you still need inference cards close to the user for a good experience."

"Kimi is open source, so in theory we download the weights and run it ourselves. But the model is so large it costs enormous resources to run. And GPUs and memory are in shortage, we can't get enough to do the inference."

"So even the price ends up around Opus 4.8's level. The model may be free, the compute isn't."
