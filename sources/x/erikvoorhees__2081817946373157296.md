There is some confusion/mistaken belief that Chinese models are run by Chinese companies in China. People hesitate to use the "open source" model because they don't trust China as a jurisdiction. 

How it actually works:

Frontier closed source models are run by the companies that made them.
• GPT 5.6 is trained & run by OpenAI
• Opus 5 is trained & run by Anthropic

But the open source models can be run by anyone
• Kimi K3 is trained by Moonshot (Chinese company)
• Kimi K3 is run by Moonshot
• Kimi K3 is ALSO RUN by anyone else (any company can run it)

If you access Kimi K3 from https://t.co/FVFlibYL6q, then you're pulling the inference from Moonshot, the Chinese company. 

But you can also access Kimi K3 from https://t.co/iUPC8ijDPN for example, in which case there is no Chinese company involved in its operation or the data therein. Dozens of others also provide it. 

So if you want the open source model, but are wary of China as jurisdiction, just go to a different source.
