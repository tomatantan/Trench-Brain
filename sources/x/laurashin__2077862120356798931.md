Johann Kerbrat explains why Robinhood built a separate instance of Lighter instead of tapping the main liquidity

"The value that we see is that a lot of these systems that we're partnering with, and a lot of these projects that we're really trying to connect to, we want to create a very unique experience for our customers. If you use the Robinhood wallet and you try to interact with the perps products that we build through Lighter, you will see that the experience is very unique"

"You don't have a table where you have to enter numbers manually like you have on most of the other platforms or competitors. You have a very sleek, easy to use UI where you can change your margin very easily, you can follow the contracts and change and replace them as well very easily. That type of unique interaction that we are focusing on requires some of the changes that we ask some of our partners, so for example in that situation with Lighter, we think it's the most important part"
