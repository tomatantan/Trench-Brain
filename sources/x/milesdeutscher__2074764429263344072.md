If you use Hermes agent, you need to install this skill.

There's a free Hermes Agent skill that automatically removes your personal data from every data broker on the internet.

It's called Unbroker. Here's what it does and how to set it up:

What it actually does

Data brokers regularly collect and sell your personal information.

Think: Name, address, phone number, email, relatives - everything.

Unbroker scans every broker site, finds where your data is exposed, and sends removal requests automatically.

It also handles the follow-up verification emails too.

(Think Incogni, but self-hosted, free, and running on your own agent).

How to set it up:

Step 1. Install Hermes Agent

TERMINAL COMMAND

curl -fsSL https://t.co/VjaSh2SnRm | bash

Or download Hermes Desktop for a no-terminal setup ( https://t.co/IOKhCwcDB6 ).

Step 2. Install the Unbroker skill

TERMINAL COMMAND

hermes skills install official/security/unbroker

Or tell Hermes "I want you to install this skill: https://t.co/Mu8y6LdFWC."

Step 3. Run it

Start a new Hermes session and send:

"Use the unbroker skill to remove my data from data brokers. Here is my consent. Run it hands-off and show me the human-task digest at the end."

It's that simple.
