🇺🇦🇷🇺 Russia hacked doorbell cameras to spy on arms shipments

Dutch intelligence says Russian hackers quietly broke into internet-connected security cameras sitting near NATO military routes.

The point was to watch the weapons convoys rolling toward Ukraine, tracking what was moving and when, straight off ordinary camera feeds.

And a lot of these were soft targets, everyday devices like home doorbell cams, easy to crack because owners never changed weak default passwords or updated the software.

Authorities have quietly warned the affected groups to lock things down.

Pretty sure half these passwords were still set to 1234.
