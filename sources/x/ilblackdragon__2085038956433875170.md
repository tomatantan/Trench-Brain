Here's my talk from @StanfordSBA BASS last week on how to build a sovereign AI stack. Open vs. closed is not the only question for AI sovereignty:

-Can you trust that you know exactly which model you’re running?
-Do you know if the prompt has been rewritten?
-Can you verify the data it was trained on?
-Did the model or hardware owner exploit your data?
-Can you learn about any topic or is usage restricted by another party?

We need verifiability at every layer.
