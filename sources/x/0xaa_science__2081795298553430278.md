老码农 Skill
Uncle Bob Martin 是位码龄近 60 年的老码农。他在推上分享了自己使用 coding agent 的经验：不读 agent 写的代码，而是让代码闯过层层关卡，才配被信任。

我把这套思想做成了开源 skill：old-coder（老码农），方便大家使用。每个关卡代表一种测试或约束，old-coder 内置 10+ 关卡，并在写完代码后生成报告供你审阅。
