找到用 Cursor App 控制本地 Cursor Agent 的方法了，藏的好深！

1. 在 Cursor 个人账号页面开启权限：Cloud Agents - Self-Hosted - Enable remot-control
https://t.co/2lV7zt9qaW

2. 在 Cursor App 点击小云朵 ☁️ 按钮，切换到 My Machines，就能切换到电脑本地 Agent 了。
