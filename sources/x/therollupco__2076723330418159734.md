Every AI agent making a transaction needs to settle that transaction instantly.

Legacy payment rails were built for humans operating on human timescales, days for ACH, seconds for Visa at best.

@jerallaire, @circle Co-founder, argues this creates a hard architectural requirement: the agentic economy must run on software money, software contracts, and software governance, or it fails structurally.

Instant settlement. Micropayments. Programmable rails.

That's a stablecoin use case, not a credit card use case.

Andy: "We're all anticipating what's going on in the future where agents will operate onchain."
