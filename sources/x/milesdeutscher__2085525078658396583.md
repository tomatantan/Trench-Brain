I think one of the best ways to become AI-native is to build "mini tools" for yourself.

Examples: a meeting note-taker, a custom notes/journaling app, a prompt optimiser skill/dashboard, and so on.

None of these require you to know how to code, but they do require you to learn Claude, iterate, learn context engineering, basics of vibe coding, etc.

The real value isn't the tool itself because, frankly, you can just pay a subscription for some SaaS.

But the actual process of building yourself is hands-down the fastest way to become AI-native.

Beats watching YouTube/consuming content any day.
