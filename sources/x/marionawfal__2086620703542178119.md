10,200 operational Starlink satellites are impressive.

But having them talk to one another is where it gets really interesting.

The V3 satellites tested on Starship all connected through laser links, while Starlink’s broadband fleet is already delivering around 800 Tbps of downlink capacity.

Now combine that inter-satellite network with Starship carrying much larger V3 deployments.

More capacity. More routes for the data. More places Starlink can reach properly.

This is becoming one very capable orbital network.
