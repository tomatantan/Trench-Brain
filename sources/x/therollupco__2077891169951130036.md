Most people hear "model routing" and think the system just picks the smartest or fastest model for the job. Jerry Yu says that's half of it.

From @intel's view, private model routing means the routing layer also checks the trust posture of wherever that model is about to run.

Is it inside a confidential computing environment?

Has the runtime been measured and matched against the trust policy?

The point that matters: routing shouldn't require blind trust in an infrastructure provider. It should run on evidence you can independently verify.

You don't take the cloud's word for it. You make it prove it.
