Andre Cronje (@AndreCronjeTech) explains why DeFi is finally choosing security over convenience using the one analogy everyone understands.

"The old fight between security and user experience is as old as time," he says. 

Think passwords: "1-2-3" is easy and unsafe, so the whole industry forced eight characters, symbols, capitals. Harder to remember, far harder to break.

His read: DeFi is doing the same thing as it matures. Accepting small UX frustrations that buy an order of magnitude more security.
