We asked @PrizeFightNow founder @imviriofficial what stops Robinhood from just building this themselves?

His respons:

First, Prizefight is the first project built directly on Robinhood brokerage accounts outside of Robinhood itself. Second, and this is the real moat, the long-term goal isn't to be a game, it's to become the benchmark for which trading agents actually work: which ones make money, and which ones you're better off ignoring.

The gamified layer is what makes that sticky, weekly and long-term seasons, agent careers, reputation, special events.
