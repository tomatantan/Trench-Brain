# 6レンズ（trench版 Skill Graph）— 1つの問い/トークンを6回考え直す

出典: makeai_ceo「第二の脳→リサーチエンジン」(2026, 本人参考指示) ＋ Karpathy LLM Wiki。
目的: 単一パスの要約(=どのAIでも出せる)を脱し、**6つの独立視点で再分析**して矛盾を表面化し、
"判断材料の成果物"を出す。**各レンズは別のリサーチャーが書いたように考え直す**(情報追加でなく視点転換)。
3つ以下だと確証バイアスから逃げられない＝最低でも contrarian を必ず通す。

> ★出力は6レンズ全部を貼るのではない。**内部で6回考え**、出力は合成結論＋確信度＋効いた矛盾だけ(簡潔)。

## 1. on-chain / data（テクニカル）
硬データだけ見る。意見排除。RugCheck(authority/LP/holders/insider)・mcap・reply・base_rate・死亡/跳躍台帳の数字。
「上がってる」でなく「$5.8k→$13.8k(+138%)・reply0」の精度。**tier1(一次on-chain)優先**。

## 2. incentive / flow（経済）
金の流れ。誰が仕込み・誰が儲かり・どのインセンティブが板を動かすか。team送金/LP構成/sniper割当/KOLが自分のポジを持つか([[onchain-verification]])。表の物語の裏の経済合理性。

## 3. narrative / social（ナラティブ）
meme/注目/KOL拡散＝[[reflexivity]]の燃料。誰が言い出し・どう伝播・CTに飛び火したか。traction(reply/KOL)の有機性。**ここが薄い噴きは死ぬ**(死亡台帳の型)。

## 4. historical / pattern（歴史・型）
過去サイクル・[[rug-anatomy]]死亡台帳・[[launchpad-economics]]跳躍台帳・[[survivor-memes]]。「これは何に韻を踏むか」。"graduated-but-empty"・"traction無しBREAKOUT→即死"等の既出の型に照合。

## 5. contrarian（逆張り）★必須
「今の見方が間違ってたら？」を本気で。コンセンサスへの**最強の反論**は何か・そのコンセンサスで誰が得してるか。
全レンズが同じ結論なら危険→これを再実行。確証バイアス・過学習(指針対策)の砦。

## 6. first-principles（第一原理）
前提を全部剥がし、板の素・トークンの素から組み直す。「皆がそう言ってる」を疑い、最も基本的な事実だけから。
