# 型: 外部イベント → token（再現するプレイブック）

複数の動線を横断して抽出した**繰り返す型**。crypto外のビッグイベントが発端になり、
trench に token を生む。しばしば **2系統に分岐**する:

```
外部イベント(IPO/世界大会/要人発言/政治)
   ├─▶ RWA/tokenized 系  … 機関フロー・先物OI・取引所採用で駆動(数字で追う)
   └─▶ meme 系           … 固有名/マスコット/物語で駆動(コミュニティで追う)
```

|---|---|---|---|
| SpaceX IPO | [[$SPCX]] | [[$ASTEROID]] | [[spacex-ipo-narrative]] |
| W杯2026 | —(物語のみ) | [[$CLUTCH]] | — |

## この型から言える示唆
- **先回り可能性**: 大型IPO・世界大会・要人イベントは事前に分かる＝発端が読める。発生前に「RWA候補」「マスコット/固有名のmeme候補」を張れる。
- **追い方が2系統で違う**: RWA側は板(OI/出来高/取引所)、meme側は物語の真偽とコミュニティ。混同すると判断を誤る([[spacex-ipo-narrative]]の反例参照: 同一発端でもショート勢と物語勢が衝突)。
- **賞味期限**: イベントに確定スケジュールがある場合(W杯等)、ピークと減衰が読みやすい。IPO等は通過後の継続フローが鍵。

## ⚠️未確認・今後
- サンプル数まだ少(2-3件)。型の確度を上げるには過去の同型(選挙/Trump発言→meme、ETF承認→token 等)を遡って当てはめる必要。
- 監視: [[watchlist]] のマクロ/外部要因層([[@elonmusk]] [[@WhiteHouse]] [[@CryptoHayes]] 等)が"発端"の早期検知点。
