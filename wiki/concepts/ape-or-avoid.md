# 魔界 ape-or-avoid — 全概念を1つの判断に束ねる

本人の core decision＝「**この pump.fun 銘柄に乗るか避けるか**」。本wikiの各概念は単独でなく、
**この1つの判断に収束する層**として読める。ここはそれらを横断合成した capstone（[[/check]] が機械適用する論理の"知識側"）。
★各層は観測→判断の順。確率を上げるだけで保証でない（[[reflexivity]]＝不可約な不確実性）。

## 根本（なぜ大半 avoid が正解か）
- [[reflexivity]]＝価格↔ナラティブの自己強化が trench の唯一のエンジン。memeはファンダが無く reflexivity が裸＝**boom/bustが純粋で速い**。
- [[launchpad-economics]]＝供給工場。**98.5%が死ぬ母集団**（実観測 base 死亡率も ~46%＋pending）。＝**デフォルトは avoid。乗るには reflexivity 点火の根拠が要る**。

## 判断の層（上から順に効く・[[predictive-study]] N=99 で重み実証）
1. **scam門（T1・即avoid）**＝[[rug-anatomy]] 赤旗（authority未放棄/insider集中/LP非対称/bundled）→ 乗る価値の前に rug れる。
2. **規模・gate**＝[[predictive-study]]: **peak mcap <10k = 死100%**／**graduated-but-empty = 死70%**（最頻死型）／mcap勢い門 = 死13%。＝小peak・空graduated は強 avoid。
3. **traction の有無と"質"**＝traction有り死12% vs 無し55%（生存を分ける）。**但し [[manipulation-playbook]] で偽traction を除外**（pumper exit誘導/協調bot投票/借用ナラ/人工social）。質を見ない traction は罠。
4. **誰が語ってるか（信頼性）**＝[[kol-track-records]]: 言及KOLの過去callの生存率（golocojp 0%死 vs ShapeFN 67%死）。track-record悪いKOLのcall＝avoid加速。live X で watchlist外の発信者も信頼性照合。
5. **物語の局面**＝[[survivor-memes]]（SOL β点火か）／[[external-event-to-token-pattern]]（イベント借用は点火条件であって生存条件でない）／[[majors-rotation-supercycle]]（マクロ流動性）。

## 統合ロジック（ape ↔ avoid）
```
scam門 NG ──────────────▶ AVOID（即・理由の前に）
peak<10k / graduated空 ──▶ AVOID寄り（死率70-100%）
traction無し ───────────▶ AVOID寄り（死55%）
traction有り but 偽(手口)▶ AVOID（見かけのtraction＝撒き餌）
traction有り×信頼KOL×mcap勢い×手口クリア▶ 相対的に APE 候補（死率は最低層）だが
                          └ それでも母集団は死＝サイズ/exit計画必須（[[reflexivity]] 反転は速い）
```

## ⚠️ この框の限界（過剰主張しない）
- 全データが同一launchpad・近時間帯＝独立性限定・現mcap近似・小Nのcell有り（[[predictive-study]] 留保）。
- traction有り×信頼の「survivor候補」も**保証でなく確率**＝[[survivor-memes]] の生存者バイアスの只中。
- reflexivity ゆえ**反転は非線形に速い**＝entry が正しくても exit 遅れで飛ぶ（[[rug-anatomy]] レバレッジの罠）。
- ＝この框は「乗る/避ける」を**確率で傾ける**もの。断定機でなく判断増幅器。
