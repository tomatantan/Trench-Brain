# 型: 再帰性（reflexivity）＝ trench を動かす根本エンジン

古典 [[canon]] から取り込んだ Soros の[[再帰性|reflexivity]]（[[soros-reflexivity|一次クリップ]]）を **trench に適用**した concept。
個別の観測（pump/death/rotation）の**下にある共通の機械**を名指す＝既存 concept 群を1つの原理で束ねる土台。

## 一行
**価格 → ナラティブ → さらなる買い → 価格**、の自己強化ループ。Soros は株でこれを見たが、
**memecoin はファンダがほぼ無い＝reflexivity が"裸で全部"**になる極限事例。株では fundamentals がループを減衰させるが、
trench には減衰させるものが無い＝**より速く・より純粋に boom/bust する**。

## trench での機械（なぜ memecoin が reflexivity の極限か）
```
誰かが買う → 価格↑ → 「mooning中」というナラティブ → 注目(reply/KOL/出来高) → 新規買い → 価格↑ …(boom)
   → どこかで限界 → ナラティブに罅 → 弱気が自己強化 → 一撃で崩落(bust) → 98.5%は死(→[[launchpad-economics]])
```
- **pump.fun の bonding curve は reflexivity を機械的に符号化**: 買うほど価格が上がる曲線＝価格とセンチメントが構造的に直結。
- **traction(reply/KOL) ＝ reflexivity の燃料計**: ナラティブ増幅チャネルそのもの。
  - これが俺の観測台帳を説明する: [[rug-anatomy]] 死亡台帳/[[launchpad-economics]] 跳躍台帳で「**traction無し×出来高先行**」の跳躍([[$AEGIS]]/[[$RO]]/[[$PHONEBLACK]])が即死寄りなのは、
    **ナラティブ・ループ無しの価格上昇＝reflexivity の燃料が無い空ぶかし**だから。bot/whale が価格だけ押しても、認知→買いの第2フェーズが点火しない＝自己強化が続かず崩れる。
  - 逆に [[survivor-memes]]（$BONK/$WIF/$PEPE）は **lore/community がナラティブ・ループを長く持続**＝reflexivity が長期間 far-from-equilibrium に留まった稀な生存。

### ★実時間の実証（2026-06-23・仮説→確証されつつある）
上の「traction無し跳躍＝reflexivity燃料切れ＝崩れる」は当初**仮説**だった。auto-track が同じ銘柄の**全弧（boom→bust）を実時間で記録**し、確証されつつある（＝古典の枠組みが自前の観測データで裏付く＝単一ソースでは見えない収束）。
- **観測（完結した弧）**: [[$PHONEBLACK]] $89.8k→**$214.3k(BREAKOUT)**→**$3.2k(-98%全損)**。reply/KOL は一度もゼロのまま。＝跳躍台帳([[launchpad-economics]])と死亡台帳([[rug-anatomy]])に**同一銘柄が両方載る**＝燃料無しの自己強化が点火せず一撃で反転した archetype。
- **観測（崩壊中）**: [[$AEGIS]]（+160%→ fading）/ [[$RO]]（+348%→ -48% fading）＝同じ traction-less の弧を辿りつつある。
- **⚠️ 未決（過剰主張しない）**: [[$MOONLAKE]] は traction0 のまま **$1M 突破（+147%）でまだ崩れていない**＝この型の**反証候補/まだ途中**。これも崩れれば確証が強まる／生き残れば「traction無しでも whale 仕込みで持続する例外」として型に但し書きが要る。**観測継続が決着をつける**（思想5: 両論を消さない）。
- **判断**: 燃料計(traction)の predictive 精度は**死側で高い**（traction0 → 崩壊が複数確認）。跳躍側の「生存するか」は traction だけでは決まらない（$MOONLAKE）＝**screening は "traction無し→危険" の側を強く、"traction有り→安全" は弱く**使うのが現データの含意。

## 既存 concept をこの1原理で束ねる
- [[launchpad-economics]]: 98.5%が死ぬ＝**bust 側が常態**（自己強化は大半が早期に反転）。graduation×traction の足切り＝ループ燃料の有無。
- [[survivor-memes]]: ループを持続できた少数＝生存。生存者バイアスは「持続した reflexivity」だけ見える錯覚。
- [[rug-anatomy]]: bust は reflexive ゆえ**突然**（じわじわでない）。holder集中/bundle はループ反転時の exit を早める増幅器。
- [[onchain-verification]]: **反転の先回り**＝ナラティブが罅割れる前に whale が抜ける動きを [[@lookonchain]]/[[@arkham]] で捕捉。
- [[majors-rotation-supercycle]]: マクロ層の reflexivity＝BTC→ETH→alt は**注目(センチメント)の再帰的ローテ**。
- [[spacex-ipo-narrative]] / [[external-event-to-token-pattern]]: 外部イベントが初期ナラティブを点火→reflexive に増幅。

## 示唆 / 賭けの仮説
- **trench にファンダ・アンカーは無い＝reflexive サイクルの"どこにいるか"が全て**。早期 boom＝乗る、燃料切れ/末期＝反転前に降りる。
- **traction(reply/KOL)を reflexivity 燃料計として読む**: 価格が動いても traction が伴わない跳躍は「自己強化が点火していない」＝持続性低（死亡台帳の型と一致）。価格×traction の同時上昇＝ループ点火中。
- **反転も reflexive＝非線形に速い**: だから損切り/exit は「ナラティブの罅」(KOL の沈黙化・onchain whale 抜け)を待つと遅い。罅の**前兆**を先行指標化する（[[onchain-verification]]）。
- ⚠️ 再帰性は**両刃**: 上方向の物語に乗るのと、下方向の物語に呑まれるのは同じ機械。強気一色の corpus では「下方向の self-reinforcing」を意識的に併記する（指針5）。
